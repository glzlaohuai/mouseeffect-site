# MouseEffect visual system

## Scene and direction

A Mac user explores a small desktop utility in daylight, looking for playful feedback and confidence that it stays out of the way. Use a light, airy surface with the precision of a native Mac tool, rather than a dramatic game aesthetic.

## Color strategy

Restrained neutral surfaces with a decisive orange action color, supported by apricot fields in the interactive demo. Tinted neutrals and OKLCH tokens. Dark warm ink for text. Color comes from the true app icon, screenshots, and particles.

## Typography

The approved brief requests the system font stack, which also supports all fourteen scripts without remote font requests. Large, tightly spaced but balanced hero heading; compact labels; readable body measure below 70ch. Arabic, Thai and CJK typography use language-specific spacing and line-height.

## Composition

Compact header, asymmetric split hero with a large interactive particle stage, an actual app library screenshot beneath it, two alternating screenshot-led feature sections, a clear purchase explanation, a short privacy statement and a useful footer. Legal pages use a narrow reading column and numbered table of contents. No repeated decorative feature cards.

## Interaction and accessibility

Native language select with a no-JavaScript submit action through a localized language directory, keyboard-operable demo controls, visible focus, skip link, semantic landmarks, stable image dimensions. Particle rendering is capped, stops offscreen and when hidden, is paused initially for reduced-motion preference, and never blocks clicks or page scrolling. Mobile stacks text before imagery; logical CSS properties handle RTL.

## Confirmed brief

The user supplied the confirmed visual and content brief in the delegation. Direction probes and north-star generated images are skipped by explicit user instruction: real product screenshots and a coded particle demonstration only. Fidelity inventory: light system-font shell, orange emphasis, original app icon, actual Chinese UI screenshots, five mouse gestures, pause control, and a calm responsive reading experience.
